# Generated Outputs

This directory is used for outputs generated by the analysis scripts.

Depending on the executed script, outputs may include:

- revised SWS values
- normalization parameters
- deterministic weight tables
- entropy-weight details
- correlation results
- exploratory partial-correlation results
- component correlation matrices
- deterministic rank-stability results
- leave-one-component-out results
- Monte Carlo uncertainty summaries
- temporal-consistency pairwise comparisons
- figures used in the manuscript

Generated files are not required to be committed to the repository because they can be reproduced from the source data and analysis scripts.
